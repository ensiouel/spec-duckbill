# Duckbill Execution

Read the constitution, specification, plan, tasks, relevant project instructions, and existing code before editing.

Work on exactly one task. Respect its dependencies and preserve unrelated user changes. If requested behavior conflicts with the specification, stop and explain that specification refinement is required.

Use normal Pi tools to edit code and run checks. Mark the task `completed` in tasks.md only after its checks pass. Otherwise leave it pending and report what remains. Do not start another task.
