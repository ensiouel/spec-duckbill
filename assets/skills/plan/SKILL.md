Read the constitution and ready specification before planning. The specification owns WHAT and WHY. The plan and tasks own HOW and execution order.

Edit only plan.md and tasks.md. Give tasks stable IDs, dependencies, status, actions, and checks. Preserve completed unaffected tasks during synchronization. Do not edit specification or code and do not start another action.
