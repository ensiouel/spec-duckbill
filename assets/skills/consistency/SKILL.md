# Duckbill Consistency

Preserve the authority order: constitution, specification, plan, tasks, code. Lower levels may add detail but may not redefine higher intent.

Analysis is read-only. Synchronization may edit only plan.md and tasks.md. Preserve unaffected work and report conflicts with clear ownership. Do not edit specification or code and do not start another action.
